# 体素居民角色交付

本文件夹可直接作为模型交付目录。共 22 套可替换造型，每套分为四个 FBX 部件：

- `heads/Head_编号/Head_编号.fbx`：头部（含发型、帽子等）
- `upper_body/upper_body_编号.fbx`：上半身
- `lower_body/lower_body_编号.fbx`：下半身
- `shoes/shoes_编号.fbx`：鞋子

编号为 1–22；同编号的四个部件组成一套造型，也可在同一骨架上混搭。所有 FBX 均带相同的 22 根骨骼和四个原地循环动作：`Walk_Forward`、`Walk_Backward`、`Walk_Left`、`Walk_Right`。游戏运行时保留一套骨架，替换相应部件的网格即可，不要叠加四套骨架。

整体缩放应用在**组装后的人物根节点**，不要单独缩放部件：9–11、21–22 号儿童为 `0.78`；14、19–20 号老人为 `0.94`；其余为 `1.00`。人物正面朝向为 `-Y`，模型单位为米，标准成人约 1.8 米。模型使用 FBX 内的纯色材质，没有外部图片贴图。

这些 FBX 已分别在 Blender 重新导入，检查了部件骨骼绑定、四个动作及循环接缝。本目录就是游戏导入所需的完整交付包。
