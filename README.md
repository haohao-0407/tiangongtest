# 森屿 · 和平殖民地

天工引擎 0.4.19 的单机 3D 体素殖民地经营原型。围绕居民、劳动、建设和农业展开，不包含战斗。

## 路径说明

| 项 | 位置 |
|:--|:--|
| 游戏工程 | 本文件同级的 `game/`（相对路径，换机器不用改） |
| 引擎依赖 | `@forgeax/engine@0.4.19`，由 pnpm 从 npm 安装 |
| 启动日志、临时文件与工具缓存 | 本仓库的 `.launcher/`（不提交 Git，不依赖固定盘符） |

## 开始

**Windows 直接双击**：`启动游戏.bat`。本机需要 Node.js 22.13 或更新版本。

启动器会选用工程指定的 pnpm 版本，缺少依赖或安装版本不匹配时自动修复；首次使用需要联网。无需全局安装 pnpm。已有正常游戏会话时会复用，异常或浏览器已断开的会话会自动恢复。

日常启动检查工具版本、依赖入口、编译结果和浏览器就绪状态。完整依赖扫描保留给 `-Check`、`-Repair` 和安装之后，避免每次启动都等待数分钟。

**命令行**：

```powershell
.\Start-Game.ps1
```

**常用操作**（在仓库根目录运行）：

| 命令 | 用途 |
|:--|:--|
| `.\Start-Game.ps1 -Check` | 检查环境与工程；不启动游戏、不自动修复依赖 |
| `.\Start-Game.ps1 -Repair` | 按锁文件修复依赖并自检，完成后退出 |
| `.\Start-Game.ps1 -Restart` | 停止本工程旧会话，再重新启动 |
| `.\Start-Game.ps1 -Stop` | 停止本工程的游戏会话 |
| `.\Start-Game.ps1 -NoBrowser` | 启动不显示窗口的浏览器，供运行验证使用 |

启动时会显示当前阶段和日志位置，失败会保留错误并返回非零退出码；双击入口只在失败时暂停。单个阶段默认最多等待 180 秒，首次下载较慢时可延长：

```powershell
.\Start-Game.ps1 -TimeoutSeconds 600
```

找不到 Node 时，可用 `-NodePath "你的 Node 安装目录\node.exe"` 指定，或设置 `GAME_NODE_PATH`。启动器也会探测系统 PATH、常见安装位置和 WorkBuddy 自带的 Node。

当前引擎使用后台服务：正常 Windows 环境下，启动命令结束后游戏仍可运行。需要结束游戏时使用 `-Stop`，不要依赖关闭启动窗口；受进程管理限制的运行环境可能另有行为。
