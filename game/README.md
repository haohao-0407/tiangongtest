# 森屿 · 和平殖民地

基于 **天工引擎 0.4.19** 的单机 3D 体素经营原型。借鉴殖民地经营与田园生活的系统联系，使用原创体素表现；不含战斗、袭击、武器或征召。

## 当前玩法

- **程序化地图**：48 × 24 × 48 格，12³ 分块；字符串种子确定丘陵、河流、沙岸、树林和建造空地。
- **居民生活**：开局三位居民，独立饥饿、休息、娱乐、情绪、健康与疾病；技能和特性影响工作。可设置十类工作优先级及四种作息。
- **劳动与物流**：居民沿地表寻路，到达目标后工作；伐木、采矿、播种、收割、搬运。地面物资由居民搬入共享仓储后才计入可用库存。
- **建设**：十二种设施，包括床、桌、灶台、工作台、研究桌、墙、门、地板、太阳能板、电池、冷藏柜与病床。材料足够时下达蓝图并预留，居民施工完成；取消未完工蓝图退还材料。
- **农业与生产**：水稻与研究解锁的玉米，生长、收获、再播种；熟食、药品、零件的库存目标订单，产物需要搬运入库。
- **科技与环境**：五项研究、昼夜、四季、天气、太阳能和蓄电、冷藏减缓腐败、小型围合房间、舒适度、疾病治疗、有限库存的友好商队及和平来客。
- **保存**：本机自动档、独立手动档、JSON 导出与导入；恢复地图、居民、需求、工作、科技和事件。
- **沙盒**：保留原来的六种无限方块材料、放置/拆除、200 步撤销重做。进入沙盒自动暂停经营。

开局已经有基础床铺、炉灶、工作台、研究桌、仓储和一片待播种农田，可以先观察居民劳动，再添建设施或开始研究。

## 操作

| 操作 | 输入 |
| --- | --- |
| 选择居民 / 执行当前规划 | 左键 |
| 返回查看模式 | 右键 / Esc |
| 暂停 / 恢复 | 空格，或顶部速度按钮 |
| 1 / 3 / 6 倍速 | 1 / 2 / 3（经营模式） |
| 移动视角 | WASD / 方向键 |
| 旋转视角 | Q / E，或中键拖动 |
| 缩放 / 复位 | 鼠标滚轮 / F |
| 墙体蓝图 / 取消规划 | B / X（经营模式） |
| 沙盒材料 / 撤销重做 | 1–6 / Ctrl+Z、Ctrl+Y |

底部菜单提供建造、规划、工作、生产、研究、贸易和事件记录。规划区域以落点为起点创建 3 × 3 格；空间不足或被占用会显示失败原因。进入沙盒后可直接改变同一张地图，恢复经营时通行性也会受影响。

## 启动与检查

当前电脑运行工作区根目录的 `Start-Game.ps1`。脚本把工具、缓存和测试临时目录指向 D 盘，调用官方开发预览并打印实际网址。

```powershell
cd D:\tiangongtest
.\Start-Game.ps1
.\Start-Game.ps1 -Check
```

工程内常用命令：

```text
pnpm typecheck
pnpm test
pnpm exec forgeax project check --json
pnpm exec forgeax project play scripts/colony-playthrough.mjs --require-ui --headless true --backend auto --timeout-ms 240000 --json
pnpm exec forgeax project play scripts/sandbox-playthrough.mjs --require-ui --headless true --backend auto --timeout-ms 240000 --json
pnpm build
```

游戏位于 `D:\tiangongtest\game`，SDK 位于 `D:\tiangong-tools\forgeax-sdk-0.4.19`，依赖与缓存使用 `D:\tiangong-tools`。换电脑需安装官方支持的 Node/pnpm，并按新机器修改 `.npmrc` 的缓存路径。

## 明确的简化与边界

这是和平经营原型，并非完整复刻 RimWorld。仓储是共享库存，没有格子容量、过滤或仓库优先级；建造材料从库存预留，没有独立逐件送材环节。寻路在地表四邻格进行，支持一格高度差，不支持多层楼或地下殖民地。

十二种设施均占一个逻辑格；已建成设施暂不支持经营拆除。房间以墙门围合的小区域判定，自动视为有顶，没有手动屋顶、清洁、房间用途和完整评分。全营地共享电网，无导线拓扑；冷藏作用于共享库存，未实现独立冷库温控。

健康使用总健康值和疾病程度，没有器官损伤、手术、义体或死亡；情绪、特性与作息为简化模型。尚无恋爱家庭、动物畜牧、服装品质、派系外交、世界地图商队、复杂叙事系统或 DLC 内容；无联机和云存档。

本机存档使用当前浏览器来源的 `localStorage`：自动档 `homestead.colony.v2`，手动档 `homestead.colony.v2.manual`。旧体素档 `homestead.voxel.v1` 只读兼容，不覆盖或删除。不同浏览器、网址端口的存档空间可能不同；请导出 JSON 备份。

实现结构见 [implementation.md](docs/implementation.md)，机制目标清单见 [peaceful-colony-scope.md](docs/peaceful-colony-scope.md)，实际检查结果见 [validation.md](docs/validation.md)。
