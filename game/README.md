# 森屿 · 和平殖民地

基于 **天工引擎 0.4.19** 的单机 3D 体素经营原型。借鉴殖民地经营与田园生活的系统联系，使用原创体素表现；不含战斗、袭击、武器或征召。

## 当前玩法

- **程序化地图**：新地图默认 250 × 250 格、24 格高，24³ 分块；字符串种子确定丘陵、河流、沙岸、树林和中央建造空地。旧 48 × 48 存档保持原尺寸和地形。
- **居民生活**：开局三位居民，独立饥饿、休息、娱乐、情绪、健康与疾病；技能和特性影响工作。可设置包含整地在内的十一类工作优先级及四种作息。
- **劳动与物流**：居民沿地表寻路，到达目标后工作；伐木、采矿、播种、收割、搬运。地面物资由居民搬入共享仓储后才计入可用库存。
- **等高规划**：点刷、拖刷或矩形框选，以固定目标标高生成填挖蓝图。规划不直接改地形；居民逐格填挖，暂停时不施工，可随时取消剩余工作。
- **建设**：床、桌、灶台、工作台、研究桌、墙、门、地板、太阳能板、电池、冷藏柜与病床等设施。建筑自动附带覆盖完整占地的整平蓝图；居民先整地，地基完成后才预约建材和施工。取消未完工蓝图退还尚未使用的预约材料，已经完成的填挖保留。
- **农业与生产**：水稻与研究解锁的玉米，生长、收获、再播种；熟食、药品、零件的库存目标订单，产物需要搬运入库。
- **科技与环境**：五项研究、昼夜、四季、天气、太阳能和蓄电、冷藏减缓腐败、小型围合房间、舒适度、疾病治疗、有限库存的友好商队及和平来客。
- **保存**：本机自动档、独立手动档、JSON 导出与导入；恢复地图、居民、需求、工作、科技和事件。
- **沙盒**：七种无限方块材料（含道路）、放置/拆除、200 步撤销重做。进入沙盒自动暂停经营。
- **结构细节**：连续两格高的砖墙自动生成窗框和外凸窗台，经营模式完成的石墙也使用同一套细节。道路根据相邻地块生成两侧人行道和路沿，相邻道路相差一格高度时生成八级台阶。源格增删、撤销重做和加载都会重新生成受影响细节。

开局已经有基础床铺、炉灶、工作台、研究桌、仓储和一片待播种农田，可以先观察居民劳动，再添建设施或开始研究。

## 操作

| 操作 | 输入 |
| --- | --- |
| 选择居民 / 执行当前规划 | 左键 |
| 返回查看模式 | 右键 / Esc |
| 暂停 / 恢复 | 空格，或顶部速度按钮 |
| 1 / 3 / 6 倍速 | 1 / 2 / 3（经营模式） |
| 移动视角 | WASD / 方向键 |
| 旋转视角 | Q / E，或中键拖动 |
| 缩放 / 复位 | 鼠标滚轮 / F |
| 墙体蓝图 / 取消规划 | B / X（经营模式） |
| 等高笔刷 | 底部「规划」→「等高整地」，设置标高、笔刷大小或矩形模式，左键拖动后松开提交 |
| 采样地面标高 | 等高工具中 Shift+左键，或「采样地面」后点击地面 |
| 建筑地基高度 | 建造面板默认采样落点标高；关闭自动采样后可指定目标标高 |
| 沙盒材料 / 撤销重做 | 1–7 / Ctrl+Z、Ctrl+Y |
| 自动窗墙 | 沙盒按 4 选择砖块，搭建至少两格宽、两格高的连续墙面 |
| 道路与人行道 | 沙盒按 7 选择道路，左键点击地面顶面铺设；替换该地表源格，不叠高一格 |

底部菜单提供建造、规划、工作、生产、研究、贸易和事件记录。农田、仓储等区域以落点为起点创建 3 × 3 格；等高工具支持可调笔刷和矩形范围。橙色表示挖低、青色表示填高、绿色表示已达标，规划面板显示剩余填挖量及受阻原因。同格同标高的规划共享劳动，不同标高会提示先取消冲突规划。进入沙盒后可直接改变同一张地图，恢复经营时通行性也会受影响。

## 墙面与道路细节

砖墙以连续两格高的墙段为一个竖向窗间，暴露的平面自动生成窗洞、窗框和向外突出的窗台。转角、邻墙遮挡和不足两格高的砖柱保留实墙。增删砖块后，相应窗间随之重新生成；经营石墙完工时也会生成窗框和窗台。

铺设道路时，相邻道路自动连接，内部共享边不生成路沿；道路与可用邻地的外边界生成约四分之一格宽的人行道。水面、树木和建筑占地会阻止相应侧边铺装。将两片高差一格的相邻地面都铺成道路后，低侧道路自动生成八级台阶，每级高 `2/16` 格，与高侧铺面相接。右键拆除道路会拆除对应地表源格，`Ctrl+Z` 可恢复源格及派生细节。

这些构件按每原格 `16×16×16` 的精度局部生成，再合并成网格；没有为每个小体素创建独立实体。存档保存源方块与建筑状态，派生网格在加载后重建。

## 启动与检查

当前电脑运行工作区根目录的 `Start-Game.ps1`。脚本把工具、缓存和测试临时目录指向 D 盘，调用官方开发预览并打印实际网址。

```powershell
cd D:\tiangongtest
.\Start-Game.ps1
.\Start-Game.ps1 -Check
```

工程内常用命令：

```text
pnpm typecheck
pnpm test
pnpm exec forgeax project check --json
pnpm exec forgeax project play scripts/terrain-playthrough.mjs --require-ui --headless true --backend auto --timeout-ms 240000 --json
pnpm exec forgeax project play scripts/colony-playthrough.mjs --require-ui --headless true --backend auto --timeout-ms 240000 --json
pnpm exec forgeax project play scripts/sandbox-playthrough.mjs --require-ui --headless true --backend auto --timeout-ms 240000 --json
pnpm exec forgeax project play scripts/pcg-playthrough.mjs --require-ui --headless true --backend auto --timeout-ms 240000 --json
pnpm build
```

游戏位于 `D:\tiangongtest\game`，SDK 位于 `D:\tiangong-tools\forgeax-sdk-0.4.19`，依赖与缓存使用 `D:\tiangong-tools`。换电脑需安装官方支持的 Node/pnpm，并按新机器修改 `.npmrc` 的缓存路径。

## 明确的简化与边界

这是和平经营原型，并非完整复刻 RimWorld。仓储是共享库存，没有格子容量、过滤或仓库优先级；建造材料从库存预留，没有独立逐件送材环节。寻路在地表四邻格进行，支持一格高度差，不支持多层楼或地下殖民地。

新建木床占 1 × 2 格，工作台占 2 × 1 格，其他设施占 1 格；旧存档和初始设施保持原占地。已建成设施暂不支持经营拆除。房间以墙门围合的小区域判定，自动视为有顶，没有手动屋顶、厚岩顶、清洁、房间用途和完整评分。全营地共享电网，无导线拓扑；冷藏作用于共享库存，未实现独立冷库温控。

当前整地消耗居民工时，不消耗或产出土方物资。标高范围为 1–22，可自由规划，但实际劳动仍需要居民可到达的相邻站位；已建建筑、农田作物和水面等冲突会显示受阻原因。树木会先自动安排清理。水域可填到水面或更高处，本轮不包含动态水流、排水和低于水面的干地施工；也不包含自动坡道或脚手架。

道路目前通过沙盒编辑，还没有居民铺路任务。台阶只处理相邻道路的一格高差；同一低格同时连接多个方向的高路面时，选择一个固定主方向生成台阶，不求解复杂多向楼梯。窗内玻璃保留粗墙碰撞，窗户不可穿行；窗框、窗台等构件不能单独编辑。当前规则不生成完整多层建筑、屋顶或任意尺寸门窗。

健康使用总健康值和疾病程度，没有器官损伤、手术、义体或死亡；情绪、特性与作息为简化模型。尚无恋爱家庭、动物畜牧、服装品质、派系外交、世界地图商队、复杂叙事系统或 DLC 内容；无联机和云存档。

本机存档使用当前浏览器来源的 `localStorage`：自动档 `homestead.colony.v2`，手动档 `homestead.colony.v2.manual`。旧体素档 `homestead.voxel.v1` 只读兼容，不覆盖或删除。不同浏览器、网址端口的存档空间可能不同；请导出 JSON 备份。

实现结构见 [implementation.md](docs/implementation.md)，机制目标清单见 [peaceful-colony-scope.md](docs/peaceful-colony-scope.md)，实际检查结果见 [validation.md](docs/validation.md)。
