# 森屿整树模型

`tree.glb` 是可独立使用的 glTF 2.0 二进制模型：树干、分枝和四层裁角树冠合成一个网格，使用顶点色，无外部贴图。根部中心为原点，Y 轴朝上，1 单位对应游戏中的 1 个方块。

模型直接来自 `assets/voxel/trees.ts` 的同一组几何部件，由 `tree-mesh.ts` 合并可见外表面。游戏按每棵树的高度与变体共享原生网格，碰撞和拾取也使用这些部件；GLB 是其中高度 4、树冠半径 2、变体 0 的独立导出，不参与运行时资源加载。

在项目根目录运行以下命令即可重新生成，避免独立资产与实际树模型发生漂移：

```powershell
node --import tsx scripts/export-tree-model.mjs
```
