# 任务 17 · 任务缺料与采集提示

右上角的「任务缺料」按物料合并未完工蓝图、制作和料理批次、待播种地块及治疗任务。每单先扣自己的预留量，再用仓库可取余额抵扣一次。栏内「缺」表示还需要多少份入库。提示将这部分拆成在途、地面待搬、已下单及仍需取得的数量。玩家自己从「规划」「工作」或「制作清单」下达指令。全部够用时面板自动收起。

## 石材、生铁与任务 18 联验

## 修改与复跑

缺口计算在[任务物料账](../../assets/colony/task-materials.ts)，界面在[缺料栏](../../assets/ui/task-materials.ts)。[现有 HUD](../../assets/ui/build-ui.ts)挂载面板并在营地快照刷新时更新。缺口根据快照重算，无需存储新的游戏数据。

在游戏目录运行下列命令。[实机脚本](../../scripts/task-materials-playthrough.mjs)准备暂停的测试存档，通过游戏界面下单、选择伐木、设置搬运、取消和读档。输出位于 `artifacts/task-materials/`。本次使用本地独立源码副本，避免并行编辑触发编译冲突。

```powershell
.\node_modules\.bin\forgeax.cmd project play scripts/task-materials-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 600000 --json
```
