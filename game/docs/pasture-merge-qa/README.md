自动化模拟另覆盖旧档中已经相邻的两个牧场、正在领入时扩建、独立围栏保留、取消空牧场后保留已建建筑。在旧档用例中，居民拆除 12 段旧围栏和门，逐件核对落地数量。入口规则要求从营地可步行抵达；旧档中如找不到可达入口，加载时保留原规划。
