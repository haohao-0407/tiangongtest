## 锚点、比例与材质

普通设备以底面中心对齐占地，按已有宽深等比缩小。石磨的长轴对齐原 2 × 1 占地。路灯按 4 格显示，吊灯从 2 格安装高度向下延伸 0.7 格。开放地块也可放置吊灯，沿用既有建造规则。墙面火把自带交付石背板，玩家可以按原入口独立放置。模型顶点保留交付材质色，使用游戏天光、方向光和阴影。火把有暖光，两款电灯根据已有供电状态显示暖光。

向导使用原模型的 22 骨骨架和四个行走片段。成年猪使用正式外观，野生与收纳后的姿态继续由原动物系统驱动。栅栏与门按已有 1 格边界缩放，转角锚点位于转折柱，T 形和十字使用交付直段组合。牧场门和设备保留静态展示姿态，实际通行、工作、供电、产出和占地均读取原游戏状态。

## 复现

在 `game` 目录使用 Blender 4.5 的后台模式，执行 `blender -b --python-exit-code 1 -P scripts/export-homestead-models.py -- "<交付根目录>"`。脚本读取正式 FBX，输出 `assets/models/homestead.glb` 和 `assets/models/guide-merchant.glb`。两份对应的导入元数据维护稳定的资源标识。截图验收使用 `scripts/homestead-models-playthrough.mjs`，通过游戏读档入口载入布置好的聚落。
