## 配置与复跑

手摇制糖台占地 2×1，无研究和供电要求。首版造价为木材 12、石材 8，建造工作量 16，每批加工工作量 6。可在[制糖台定义](../../assets/colony/sugar-press.ts)调整。该文件也定义了地图上可见的双辊、手柄和糖锅。[建造卡图标](../../assets/ui/sugar-press.png)独立于建筑图集。建筑与配方分别在 `contracts.ts` 和 `recipes.ts` 注册，外观和建造卡分别接入 `view.ts` 与 `build-ui.ts`，图标列入 `guide.ui.html.meta.json`。

在游戏目录运行下列命令。[实机脚本](../../scripts/sugar-press-playthrough.mjs)载入平地测试存档，预置三名居民、仓储区、炉灶、建材和食材。随后从建造菜单摆放设备，从制作清单下单、取消。为分开观察糖落地和入账，脚本先关闭居民搬运，再从工作面板开启。截图和读数写入 `artifacts/sugar-press/`。

```powershell
.\node_modules\.bin\forgeax.cmd project play scripts/sugar-press-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 480000 --json
```

本轮使用包含并行改动的独立源码副本，以 1280×720 单视口完成 99 步，控制台及页面错误均为 0。独立副本通过类型检查和 234 项回归测试。依赖身份检查使用实际安装依赖的主项目目录，并已通过。交付位于本地工作区。
