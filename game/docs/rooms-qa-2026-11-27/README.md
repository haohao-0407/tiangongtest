# 建筑与房间验收 · 2026-11-27

用木墙、砖墙、温室墙和石门围起一间房，点选桌子可以查看房间面积、舒适度和清洁度。沿用原有规则，只有完工的墙和关上的门参与围合，本层房间最多识别 120 格。

| 操作 | 游戏内观察 |
| --- | --- |
| 在关门时点选桌子 | 室内 25 格，舒适度 42/100，清洁度 100/100。[截图](01-inside.png) |
| 点击石门详情中的开门按钮 | 门扇转到边缘，可见开启状态。[截图](02-door-open.png) |
| 开门后再点桌子 | 桌子显示位于室外。[截图](03-outside.png) |
| 关门，通过设置菜单存档并重载 | 读档后石门仍关闭，点选桌子仍显示室内 25 格。[截图](04-reloaded.png) |

自动测试用另一间 9 格房间验证了拆墙后室内消失，补墙完工后重新识别，读档保留结果。旧存档里没有记录开关状态的石门按关闭处理。摆放、旋转、通路和居民施工沿用现有测试。
