# 任务 19 · 居民寻路与人群推挤

2026-11-28，共享本地工作区。附身角色可以从两名紧贴的居民之间走过。床和工作台夹出单格通道时，居民会在有空间的一侧让行，到石墙尽头会停住。被挤离工作位置的居民可以带着原订单走回来。

最终代码通过引擎实机 77 步，生成 10 张截图，页面错误、控制台错误和输入警告均为 0。项目检查、类型检查、241 项项目回归以及下列专项回归通过。

## 实机判据

使用 32 × 32 的平地存档预置家具、人物和路线。墙边场景中的木地板施工单由游戏正常派给第二名居民。验收通过居民名单选人、按 R 附身、按住 A 推行，再松开。暂停期间隔离了自主闲逛，恢复时间后检查实际施工。坐标、订单和建筑完成状态见[关键读数](./readings.json)，引擎步骤和错误计数见[运行记录](./play.json)。

| 操作 | 判据 |
| --- | --- |
| 开阔地走进两个紧贴的居民 | 两人各自平移超过 0.1 格，玩家穿过两人原站位。松键后再观察 0.8 秒，两人坐标保持一致。 |
| 把同样的队形推向石墙 | 两侧放床和工作台。角色脚高保持 5，人物中心间距至少 0.56 格，身体边缘留在通道内。玩家停在 x=24.83，松开后原工人的订单编号保留。[推前](./03-wall-before.png) · [松开后](./04-wall-released.png) |
| 放开工人并恢复模拟 | 每次采样检查同一施工单仍由原工人负责，直到该地板建成。恢复模拟后耗时 6.5 秒。 |
| 从两端进入长 6 格、宽 1 格的通道 | 两人原目标分别在对侧 x=27.5 和 x=18.5。沿途检查身体间距、脚高及与家具的距离，12.5 秒时读到两人均已抵达。[抵达对侧](./07-bottleneck-passed.png) |
| 保存、重载、恢复时间 | 暂停时的位置逐人一致。重载后，等待工作与休息的居民仍可行走并保持间距。 |

## 专项回归

- 经理提供的三人起点为 x=23.50、24.10、24.66，同一排 z=25.50。玩家每次前进 0.04 格，92 次全部走通，终点 x=27.18。两人分到 z=26.060 和 24.940，全部角色单步水平位移最大 0.049 格。
- 相同队形推向石墙时，最前居民的中心停在 x=25.701，身体半径 0.28，墙面 x=26。保持推行输入的最后 20 步坐标完全相同。将石墙换成高三格的地形后，再次通过边界断言。
- 三人同时去一张餐桌，选到三个不同的可达站位并吃完饭。另让三人去同一个地格，三人均结束行走，再观察两秒无重叠或漂移。
- 玩家在向导和裁缝之间穿过，裁缝随后走完存档中的原路线。从高处向另一人头顶落下，受落点影响的居民横向让开，玩家最终落在地面。
- 商人接触、高差及共用餐桌的判据在模拟层验证。篝火晚会的行进路线已核对，本轮未单独实机复验晚会、楼梯推挤及五位商人同时通行。玩家原截图用于还原床和工作台的拥堵布局，实际验收使用可复跑测试存档。

## 运行入口

从仓库的 `game` 目录执行。

```powershell
node scripts/crowd-fixture.mjs --check-crowd
./node_modules/.bin/forgeax.cmd project play scripts/resident-movement-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 600000 --json
./node_modules/.bin/vitest.cmd run --reporter=dot --maxWorkers=2 --testTimeout=20000
./node_modules/.bin/tsc.cmd --noEmit
```

居民工作、闲逛和赴宴使用居民行进逻辑。向导与四位职业商人原有独立行走逻辑和开门权限，现在步进时也检查周围人物。附身玩家保留逐轴静态碰撞，每个小步先检查体素、家具、树和生成构件，再尝试推动邻人。连推时全组都能站稳才移动，过密时停住。相关实现见[殖民地模拟](../../assets/colony/simulation.ts)和[附身移动](../../assets/voxel/runtime.ts)。重现场景见[专项回归](../../scripts/crowd-fixture.mjs)和[实机脚本](../../scripts/resident-movement-playthrough.mjs)。
