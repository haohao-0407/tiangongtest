# 整棵树木

自然树由 `VoxelWorld` 保存独立的 `TreeInstance`：稳定 ID、根部位置、树干高度、树冠半径、配色与四向旋转。地形原始方块不再混有自然生成的原木和叶块，玩家手放原木仍是普通方块。`trees.ts` 的部件定义同时服务模型、选取、碰撞和占据检测。

游戏里的每棵树只有一个渲染实体，树干、分枝、四层削角树冠合并为网格；相同尺寸与配色共享网格，旋转只修改实体变换。选中时整树高亮。`assets/models/tree.glb` 是同一份几何导出的可复用模型，底部居中，顶点色，无外部纹理；`node --import tsx scripts/export-tree-model.mjs` 可重新生成。

查看模式点树干、分枝或树冠会打开同一份详情。伐木订单以树 ID 去重，居民到达树干旁才开始劳动，完成时原子移除整树，并在根部产出树干高度 × 6 的木材。木材继续沿用现有搬运和实体库存系统。树冠交叠仍保有各自身份，删除不会遍历附近树叶；沙盒删除不产资源，已完成伐木不能通过撤销重复刷木材。

整地净空和建筑完整体积涉及的树会作为施工前置任务清理。玩家碰撞检测精确部件盒，居民寻路保守检查脚部与头部占据格，道路边缘检测树木占用。沙盒保护仍站立树木的根部地基，撤销恢复会检查已有设施和人物，避免把树恢复到占据位置。

树列表写入世界存档的 `treeVersion: 1` 与 `trees`，整树删除、撤销、重做都更新世界修订。旧版 48 × 48 和当前 250 × 250 地图按原种子识别原始自然树：保留完整存活树干、已砍树不复活、清理遗留的自然叶块，保留用户独立放置的方块。旧伐木任务迁移至树 ID，与已完成设施冲突的自然树在验证存档后无收益清理。
