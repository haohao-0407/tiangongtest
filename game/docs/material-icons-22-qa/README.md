# 任务 22 · 正式材料与银币图标

2026-11-28，八张交付 PNG 已按原名归档，逐文件与微信交付目录核对，内容完全相同。正式游戏加载七张 32 × 32 透明界面图。钢铁原图为 2048 × 2048，其余为 512 × 512。运行图按原像素网格最近邻缩小，将可见轮廓居中，保留透明留边。界面沿用像素采样。[八张原图及替换版](../../art/material-icons/) · [正式界面图片](../../assets/ui/material-icons/)

| 交付图 | 游戏物品 ID | 核对依据 |
| --- | --- | --- |

两款银币在 14、16 像素时都保留斜立的币缘和高光，有纹版的内圈细节在 20、32 像素时更容易辨认。小尺寸下轮廓同样清晰，按约定默认使用素面版。替换时把归档中的 `silver-engraved.png` 覆盖到运行目录的 `silver.png`，沿用原物品 ID。[实际尺寸及两倍放大对照](./coin-comparison.png)

## 玩家界面验收

| 玩家操作 | 核对结果 |
| --- | --- |
| 打开仓库，依次选「方块」「非方块」 | 逐格检查了六种材料和银币。32 像素图与名称、数量分开显示。[方块](./01-warehouse-blocks.png) · [非方块](./02-warehouse-cloth-and-silver.png) |
| 打开制作清单，查看加工材料 | 木板、石砖、钢铁和布料的成品图均匹配，钢铁一行列出生铁原料。[制作清单](./03-material-recipes.png) |
| 操控预置背包的居民 | 七个快捷栏图标均为 25 像素，右上余额使用 16 像素银币。[角色界面](./04-hotbar-balance.png) |
| 右键向导、安排住房、翻到布料 | 布料货架图 48 像素，回收栏 20 像素。银币在货架价旁为 14 像素，商店余额和报价确认旁为 16 像素。[购买报价](./05-shop-cloth-price.png) |
| 确认买入一份布料，保存、重载并打开仓库 | 本场报价 19，余额由 30 减至 11。订单使用 14 像素银币。读档后订单仍在，仓库银币为 11。[预留后](./06-reserved-payment.png) · [读档后](./07-reloaded-warehouse.png) |

上述检查既读取界面图像的实际显示尺寸，也将界面加载的图片与交付运行图逐一比对 SHA-256。木箱、随从背包、拖拽预览共用同一物品绘制函数。任务缺料栏也接入此函数；这些入口本轮仅作代码核查。场景中的仓储包裹沿用原有占格和外观。[界面入口](../../assets/ui/build-ui.ts) · [商店](../../assets/ui/guide-shop.ts) · [缺料栏](../../assets/ui/task-materials.ts) · [UI 资源登记](../../assets/guide.ui.html.meta.json) · [尺寸样式](../../assets/guide.ui.css)
