# 第一位商人兼向导

本轮交付地图右键交易、回收栏、首位 NPC 入住与环境报价。引导剧情留到后续。两个对话在当前项目目录工作，复用已有房间、银币库存、物品价格及按件冷藏加价。

## 08 向导商店与回收栏

用户已确定首版货架共十项，包括七种基础种子以及布料、小麦和面包。后三者试做基础售价分别为每份 20、18、96 银币，均为可调值。

采购也要派居民取货。首版按订单报价预留银币，居民到向导处实际领货时支付对应金额，送回匹配的专用仓或普通仓后才增加可用库存。订单显示待取、在途和已入库数量，大单可分趟。验收时对照货物和余额在各步骤的变化，并覆盖等待和存读档。

玩家从总仓的可用库存选择有价物品与数量，确认出售时预留货物并发布搬运任务。居民实际到仓储取货，再把货交给地图上的向导。每次交付才结算对应银币。大单按搬运上限分趟，界面显示待取、在途和已交付数量。首版暂以确认时的报价锁价，部分交付按累计交付额结算差额，避免逐趟取整改变总价。无人接单或通路受阻时保留订单。

用户提供的[向导立绘原图](../art/guide-portrait.jpg)用于商店左侧。按原比例摆放，实机截图需能看清人物的脸、帽檐和抬起的手。

向导用银币出售七种基础种子包，后续缺少获取途径的种子也由向导供货。种子基础售价暂沿用历史参考值每包 2 银币，作为可调初值。向导回收所有已定价物品，按统一价格配置生成回收清单。新物品配置价格后应自动出现在可回收范围内。对向导也出售的物品，配置合理的回收价并校验双向交易。有效的冷藏件数和住房环境按既有报价规则结算。

商人初始在营地可达处，有住房后仍是同一位 NPC。玩家在地图右键点他打开商店并直接看到回收栏。按用户 JPG 布局，左侧人物，右侧商品台座、物品图和价格。清楚区分玩家买入与交给商人回收，显示数量、最终报价和银币余额。首版货架及基础价集中配置，优先沿用已有物品和价格。用现有货币与物品系统实际结算，检查取消、连续点击、货物或银币不足、读档和仅有效件数享有冷藏加价。

08 负责地图角色和右键命中、商店画面、交易指令和最终扣物加币。08 负责按 09 提供的价格系数接通并实测双方功能。最终验收含地图右键与草图对照图、实际买卖前后物品和余额、同物品不同环境的报价。

## 09 向导入住与环境定价

09 负责模拟层的住房归属、存档、环境系数和统一报价逻辑。首版建议入住条件为已围合的可达房间，至少 6 格，内有一张床及一张桌子。基础条件集中配置，短暂打开房门不应导致立即迁出。无房可在营地交易，基础系数为 1。住房位置、状态和环境分通过现有模拟快照提供给 08，地图上的商人由 08 负责，避免重复生成。

建议将舒适度和清洁度各占一半计算住房品质，环境改善时 NPC 卖价下降、回收价上升，首版相对基础价各最多浮动 10%。最终交易按银币整数计，保持同一物品买入再卖出不会凭空获利。回收时区分冷藏有效件数和普通件数，先使用各自基础回收价，再乘环境系数。UI 预览和实际结算共用同一报价函数。

## 09 提供给 08 的接口

从 `game/assets/colony/guide-housing.ts` 导入 `quoteGuideTrade`。玩家买入传 `side: 'buy'`，玩家交货传 `side: 'recycle'`。两个方向都传同一 SKU 的基础售价与回收价，回收专用品可传 `baseBuy: null`。08 负责货架、库存检查和银币结算。

```ts
const quote = quoteGuideTrade({
  side, baseBuy, baseRecycle, count, premiumCount, housing: colony.guideHousing,
});
// 返回 { total: number, normalCount: number, premiumCount: number, factor: number }
```

`count` 是本次交易的正整数件数。`premiumCount` 是其中当天仍有效的冷藏件数（可省略，默认 0）。总价按整单计，买入向上取整，回收向下取整。支持双向交易的 SKU 建议留出覆盖冷藏加价及环境浮动的价差。无效参数会抛错，按钮预览与命令结算都应使用有效数量和当前住房。

`ColonySnapshot.guideHousing` 始终存在。字段为 `npcId: 'guide'`、`status: 'camp' | 'housed'`、`position: [x,y,z]`（地图站位，格心）、`bedId: string | null`、`roomId: number | null`（本次快照的房间编号）、`comfort`、`cleanliness`、`quality`（0–100）及 `buyFactor`、`recycleFactor`。营地两系数均为 1。开门期间可保留住房，此时室内检测暂时消失，`roomId` 可为 null。模拟内可取 `sim.guideHousing`；地图和界面使用快照，无需自行计算站位或报价。
