# 天工体素 · 2D 美术需求

2026-11-27 核对。玩家在向导处用银币购买种子、布料和食物，也会在制作面板、仓库和背包中看到同一种物品。请优先让这些物品在最小的库存格里也能一眼认出。批次为项目经理建议，交付尺寸为建议工作规格。

| 批次 | 交付物 | 画面要求 |
| --- | --- | --- |
| 第一批，2 枚 | 布料、银币 | 布料用叠布或布卷，与白色羊毛团区分。银币要能在余额和标价旁的小尺寸位置辨认。两者目前都用界面符号。 |
| 第一批，6 枚 | 原木、木板、石材、石砖、生铁、钢铁 | 优先用轮廓区分三对原料与成品。原木带截面，木板成摞，石块不规则，石砖有切面，生铁粗糙，钢材整齐。游戏内“原木”显示名为“木材”。 |
| 第二批，5 枚 | 药品、零件、泥土、通用生食、通用熟食 | 生食与熟食是游戏里独立的库存项，已有面包和煎鸡蛋等具体料理图。 |
| 第二批，3 枚 | 锤子、木斧、石镐 | 用于工具栏和背包，现在显示系统表情。若美术组已有工具源图，直接提供透明底导出。 |
| 随模型交付 | 挤奶器、鸡窝、牧场门、剪毛台、织布机、制糖设备的建造菜单缩略图 | 由 3D 出统一角度的透明渲染，2D 统一裁边和对比度。手摇石磨与栅栏已有菜单格，换正式模型后更新对应缩略图。 |

**可选的界面精修**　保鲜、冰镇各 1 枚可叠加的小角标，使同一堆货物部分有加价时还看得清物品和有效件数。向导商品台座、回收栏框、报价牌也可做一套皮肤。现有界面已有布局及文字，这一项单独估价。

**交付建议**　每个物品一张透明 PNG，加可编辑源文件。物品图建议用 512 × 512 的统一画布，另看一次 32 × 32 缩略效果。图片保留轮廓和透明留边，名称、数量、价格由界面叠加。包内小麦种子、面包、羊毛三张原图供比对。

**已有图可沿用**　向导立绘、七种在售种子包、八种作物、九种料理，以及牛奶、鸡蛋、羊毛、糖、面粉、奶酪、油、蓝莓酒和肉类都有 PNG。牛奶、鸡蛋、面包及蓝莓千层酥优先把原图交技术美术制作地面和搬运用的物品牌。
