# 森屿：和平殖民地实现

目标：使用天工原生 ECS、渲染、InputSnapshot、资产生命周期和前端 UI，在体素建造底座上实现和平经营循环。战斗、袭击、征召和武器不在范围内。

## Template Disposition

- 保留：game-3d 的官方项目配置、稳定 Engine/Frontend 插件 GUID、UiAsset 身份、程序化 daylight 环境。
- 替换：第三人称场景、角色、物理与指针锁定控制替换为体素区块、俯视相机、体素 DDA 拾取和建造操作。
- 移除：未使用的样例场景/角色/花瓶/碰撞体/材质与对应测试、插件引用，避免样例物体混入游戏。

## 模块

- `assets/voxel/model.ts`：确定性种子生成、方块数组、区块脏标记、事务历史、存档与射线拾取；无引擎依赖。
- `assets/voxel/mesh.ts`：只为可见面创建带硬边法线和顶点色的区块网格。
- `assets/colony/contracts.ts`：居民、资源、订单、研究和建筑的共享数据契约。
- `assets/colony/simulation.ts`：无引擎依赖的经营模拟；时间、寻路、需求、工作和持久化的权威数据。
- `assets/colony/view.ts`：将模拟快照转换为原生 ECS 体素居民、设施、蓝图、农田、物资堆；仅显示，不反向修改模拟。
- `assets/voxel/runtime.ts`：原生 Engine Plugin，管理相机、昼夜光照、网格资产和输入；将玩家指令交给模拟，发布只读投影。
- `assets/ui/build-ui.ts`：原生 Frontend Plugin 的 UI 控制器，经消息端口与 Engine 通信，在前端保存本机进度。

## 数据与生命周期

地形继续使用 48×24×48 有限体素世界与确定性生成器。居民工作在地表网格上寻路，建筑位于地表；不是任意多层三维殖民地寻路。

Engine Worker 持有地图和 ColonySimulation；UI 通过端口发送指令并显示快照，只有前端访问本机存储。v2 存档封装地图序列化和完整模拟数据。先在临时世界校验、加载，再替换当前世界，避免损坏存档部分覆盖游戏。

原始方块编辑保留在沙盒工具中，进入时暂停经营模拟。经营施工使用订单、材料和劳动；沙盒保持无限方块与撤销历史。两者共享同一地图，因此沙盒地形编辑会影响恢复运行后的通行性。

地形修改只重建脏区块；居民与设施视图共用立方体网格和材质缓存，模拟和显示实体分离。插件 effect 结束时解除消息监听、系统、资产和所有实体。
