## 模拟边界

- 镇上预置五间合格房屋，向导仍须玩家分房。无房的采购和回收命令均被拒绝。镇边行走的位置从 (19.5, 5, 19.5) 到了 (20.5, 5, 19.5)。四个职业同一日达标，五人分获五个不同房间和床位。
- 从厨师处买入 1 个面包支出 89 银币，居民到本人处领取并入库，厨师累计仍为 12 件。
- 厨师收 14 个番茄，首趟 12 个实付 154 银币；裁缝收 14 份羊毛，首趟 12 份实付 46 银币。两笔都在首趟交货后取消，分别退还余下 2 件。
- 活动期内超额提交被拒绝。5 份活动订单交付 2 份后过期，再取消只归还 3 份额度。另一单在运输中失去住房时暂停收款，补床、重新分房并读档后，仍兑现 725 银币。
- 旧档已有有效指定床位时保留。旧向导完整收据及尚在订单上的已交付数可恢复一次，重复读档不重算。旧日志已经淘汰且订单已经删除的历史数量无法还原。[边界读数](./simulation.json)

## 复跑与范围

在 `game` 目录执行。此次为避开共享源码同时改动，实机使用固定源码副本、项目已安装的引擎和 1280×720 视口。脚本预置 32×32 平地、房屋和库存，用普通模拟命令准备在途存档，跳过活动日之间的空等。玩家在运行器内推进时间、开日历和手动存读档，居民按正式移动与交货逻辑完成付款。镇上近距离右键与商店交互由任务 14 另行验收。

```powershell
node scripts/specialist-settlement.mjs
./node_modules/.bin/forgeax.cmd project play scripts/specialist-settlement-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 420000 --json
```
