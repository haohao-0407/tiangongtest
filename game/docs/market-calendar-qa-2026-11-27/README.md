# 13 · 集市日历与收购预告

点击画面顶部的日期可查看今天及后六天。日历列出已搬来的商人、玩家已交付的件数和已安家商人的收购公告。公告显示公布日、起止日、商人、货物、价格倍率和可预订余量。已截止的公告另保留一天，方便核对。

## 复验

在游戏目录运行。代码分工与可调用接口记在[任务卡](../四位商人与集市日历.md)。浏览器断言、截图及模拟存档生成步骤见[验收脚本](../../scripts/market-calendar-playthrough.mjs)。

```sh
pnpm exec vitest run assets/colony/__tests__/market-calendar.test.ts
pnpm exec forgeax project play scripts/market-calendar-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 900000 --json
```

共享项目通过引擎项目检查与类型检查。两项专项测试覆盖四个职业的货物和额度、已安家者抽选、重复排期、读档、超额拒单及截止后的原单退额。浏览器在固定源码副本上通过，分辨率 1280×720，页面与控制台错误均为零。浏览器操作由脚本直接点击日期和关闭按钮，引擎报告的 steps 计数为 0。七个检查点逐一对比了浏览器界面与引擎读出的模拟快照。[实机读数](./readings.json) · [引擎报告](./play.json)

截图使用裁缝的「冬衣赶工」。脚本预置两间房和仓库布料，在营地模拟内执行分房、居民交货、下单和撤单，跨日时把时钟移到午夜前再推进。浏览器读取这些连续存档，并另做一次完整重载。其余三种职业活动通过纯逻辑测试。走到商人本人面前交谈、操作商店的连续试玩归任务 14。

## 文件与排期

- `assets/colony/market-calendar.ts` 实现排期、进行中查询、预留与退额。首次安家后在 2–4 天内开始首场收购，使用世界种子确定日期。首次入选的多人可在同一周分别发布。
- `assets/ui/market-calendar.ts`、`assets/ui/build-ui.ts` 和 `assets/guide.ui.html`、`assets/guide.ui.css` 提供日期按钮和公告界面。栏目只读取玩家可知的来镇、安家、交货及活动信息。
- `assets/colony/__tests__/market-calendar.test.ts` 检查日期边界与各职业额度。活动品类和倍率引用现有 `specialist-catalog.ts`。任务 12 在模拟存档与订单路径调用日历接口。
