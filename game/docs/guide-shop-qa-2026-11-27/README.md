# 08 向导商店与回收栏

在地图找到「向导商人」，右键人物或名牌即可打开商店。左侧是用户提供的等比全身立绘，右侧的三座台座支持翻页，下方回收栏列出总仓里有价格且有可用库存的物品。选择商品、调整件数、确认报价后，订单会显示负责居民、在途与已交付件数、预留与已付银币。[地图实机](./01-map.png) · [草图与实机并排对照](./layout-comparison.jpg)

货架共有十项。白菜、番茄、甘蔗、小麦、土豆、韭葱和玉米种子包的基础买价均为 2 银币，回收价为 1。布料、小麦、面包的基础买价分别为 20、18、96，基础回收价为 8、10、60。回收清单直接使用资源价格配置，目前共 24 项。住房和冷藏报价使用 09 的统一函数。

## 游戏内交易

使用平地验收存档、一位开启搬运的居民和普通总仓，从营地开始。ForgeAX 自带浏览器在 1280 × 720 下通过 218 步试玩，控制台和页面错误均为 0。为避免其他对话同时写入导致打包冲突，本次游戏使用本地固定副本。随后共享工作区另有牧场和仓库搜索改动。[引擎记录](./play.json) · [逐阶段库存、实际仓位、居民位置、订单与界面文字](./transactions.json)

## 模拟与按钮检查

- **取消采购**。首趟 12 包种子已付 24 银币，余 1 包的 2 银币退回，可用银币从 4 回到 6。12 包在居民所在位置落地，随后全部被搬回仓库。
- **取消回收**。居民取货后取消当天订单，14 个面包恢复可用，仍有 2 个保留当天的保鲜资格。银币保持 30。
- **锁价与等待**。无搬运工时，订单跨日保留 864 的报价。次日恢复搬运后实收 864。已入住且房门关闭时，居民持货等待，开门后按最初的 928 完成交付。无可用仓位时已付布料停在途中，恢复普通仓和建材专用仓后优先进入建材专用仓。[模拟记录](./simulation.json)
- **连续确认**。对同一商店确认按钮连续触发两次，只登记一单，30 银币中只预留 2 银币。该项使用商店界面组件和实际营地模拟。[按钮记录](./double-click.json)

## 实现与复验

交易清单位于 `assets/colony/guide-shop.ts`，资源回收基价位于 `assets/colony/contracts.ts`。订单预约、搬运、取消、存读档和交付结算在 `assets/colony/simulation.ts`。地图人物、命中和名牌使用 `assets/colony/view.ts`、`assets/voxel/runtime.ts` 和 `assets/voxel/zone-selection.ts`。商店与立绘位于 `assets/ui/guide-shop.ts`、`assets/ui/build-ui.ts`、`assets/ui/guide-portrait.png` 和 `assets/guide.ui.*`。

在游戏目录运行下面两项可复验交易。此次项目检查、类型检查和 128 项营地回归测试均通过。交付在本地工作区。

```sh
pnpm exec forgeax project play scripts/guide-shop-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 420000 --json
node scripts/guide-shop-settlement.mjs
```
