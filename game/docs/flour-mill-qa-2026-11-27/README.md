## 实现与复跑

建筑成本、尺寸、阻挡和建造工作量见[建筑定义](../../assets/colony/contracts.ts)，配方、工作站与每批工作量见[生产配方](../../assets/colony/recipes.ts)。两种配方共用居民取料、工作站排单、取消返料、站旁掉落和仓储搬运逻辑。[工作站与物流](../../assets/colony/simulation.ts)

石磨在地图和摆放预览中显示木座、双层磨盘和手柄。建造卡使用独立的石磨缩略图。[场景外观](../../assets/colony/view.ts) · [菜单](../../assets/ui/build-ui.ts) · [图集](../../assets/ui/building-icons.png) · [图集索引](../../assets/ui/building-icons.json) · [图集生成脚本](../../scripts/render-building-icons.py)

共享项目在启动验收时出现资源修订冲突，最终运行使用当前源码的隔离副本和项目已安装的引擎。脚本准备平地存档，随后用游戏建造卡、地图点击、制作清单和工作面板操作。脚本通过游戏计时按钮的处理函数暂停读数。单视口 1280×720，实机报告通过 97 个步骤，控制台错误、页面错误和输入警告均为零。开发期间通过项目检查、TypeScript 检查和 223 项已有测试。[实机脚本](../../scripts/flour-mill-playthrough.mjs)

从游戏目录复跑，截图和逐阶段读数写入 `artifacts/flour-mill/`。

```powershell
.\node_modules\.bin\forgeax.cmd project play scripts/flour-mill-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 480000 --json
```
