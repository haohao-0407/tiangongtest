# 09 · 向导入住与环境报价

首版入住需要至少 6 格的封闭房间、一张完工木床或双人床、一张完工餐桌，以及从营地可抵达的床边站位。木门和石门可由玩家开启，计入可达路径。房间识别沿用现有的 120 格上限。向导优先保留原床，原房失效时才寻找其他合格住房，无房时在营地交易。

舒适度与清洁度各占一半。品质 0 的两种报价均为基础价，品质 100 的买入价下调 10%，回收价上调 10%。回收先计算普通件和当天仍有效的冷藏件，冷藏件基础回收价加 20%。整单买入向上取整，回收向下取整。对于也上架出售的商品，回收总价另受最优环境买入价限制，以避免来回交易赚取差价。

## 复验步骤

1. 在 `game` 目录运行 `pnpm exec forgeax project play scripts/guide-housing-playthrough.mjs --require-ui --headless true --backend auto --viewports 1280x720 --timeout-ms 240000 --json`。脚本装入一份预建了 25 格房间、石门敞开、尚无住房归属字段的旧档。
2. 地图点选石门并关门，向导取得床位。点选餐桌可查看房间面积、舒适度和清洁度。再次开门，检查室内识别和住房快照。
3. 在设置的「世界与存档」中保存家园，重载游戏，再次关门。核对整个过程中同一向导、床位、站位、环境数据和双向报价。

验收脚本将住房快照传给正式报价函数，按 3 个面包、其中 1 个冷藏有效核价。商店界面的点击交易与实际银币结算由 08 单独验收。
